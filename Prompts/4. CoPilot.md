# Adding to DaisyUI package

I have new components I wish you to add to @DaisyVCLpkg and @DaisyFMXpkg

- I want to create Delphi components based on the UI elements found at https://daisyui.com. 
  - These are Tailwind CSS plugins. 
  - I am only wanting to create the look, feel and behaviour of a large number of these
- I need both a VCL and an FMX version of these components
  - The VCL will likely have to use GDI+/Direct2D.
- These components should be added to @DaisyVCLpkg and @DaisyFMXpkg

Just like the other components all new components must inherit from TDaisyControl for VCL and FMX.


## New components

Anything that is common and that all components require should be placed into TDaisyControl

## NOTE: 

- I don't require pixel perfection, but the closer we can get to look, the better
- Not all of the components are needed, not will all of them be named in the same manner

Please add the following:

* TDaisyChatBubble, TDaisyFmxChatBubble :
  * Found at: https://daisyui.com/components/chat/
  * See sections : chat-start and chat-end, Chat with image, Chat with image, header and footer, Chat with header and footer, Chat Bubble with colors
  * We will need to be able to use Color Emoji fonts and SVG for this component

* TDaisyCountdown, TDaisyFmxCountdown :
  * Found at: https://daisyui.com/components/countdown/
  * See sections : Countdown, Large text with 2 digits, Clock countdown, Clock countdown with colons, Large text with labels, Large text with labels under, In boxes

* TDaisyList, TDaisyFmxList :
  * Found at: https://daisyui.com/components/list/
  * See sections: List (second column grows - default), List (third column grows), List (third column wraps to next row)
  * We will need to be able to use Color Emoji fonts and SVG for this component

* TDaisyStat, TDaisyFmxStat :
  * Found at: https://daisyui.com/components/stat/
  * See section: Stat, Stat with icons or image, Centered items, Vertical, With custom colors and button
  * We will need to be able to use Color Emoji fonts and SVG for this component
