# Adding to DaisyUI package

I have new components I wish you to add to @DaisyVCLpkg and @DaisyFMXpkg

- I want to create Delphi components based on the UI elements found at https://daisyui.com. 
  - These are Tailwind CSS plugins. 
  - I am only wanting to create the look, feel and behavior of a large number of these
- I need both a VCL and an FMX version of these components
  - The VCL will likely have to use GDI+/Direct2D.
- These components should be added to @DaisyVCLpkg and @DaisyFMXpkg

Just like the other components all new components must inherit from TDaisyControl for VCL and FMX.


## New components

Anything that is common and that all components require should be placed into TDaisyControl

## NOTE: 

- I don't require pixel perfection, but the closer we can get to look, the better
- Not all of the components are needed, not will all of them be named in the same manner

### Please add the following ( not a part of Daisy UI, but we will need them ):

* TDaisyForm, TDaisyFmxForm:
  * Similar to a TForm
  * Differs in that it is aware of TDaisyControl themes and .ThemedTitleBar
  * On .FormShow it must have TDaisyControl.ThemedTitleBar := True;
  * It needs an ApplyTheme(const aTheme: TDaisyThemeKind) public method
  * When you have created this all the demos need to use this form variant


### Please add the following:

* TDaisyTextInput, TDaisyFmxTextInput :
  * Found at: https://daisyui.com/components/input/
  * See sections : All sections
  * Note: I do not want to have double borders when this control is focused
    * Changing to a darker color would be enough
  * We will need to be able to use Color Emoji fonts ( for text entry ) and SVG ( for the icons ) for this component 

* TDaisyTextArea, TDaisyFmxTextArea :
  * Found at: https://daisyui.com/components/textarea/
  * See sections : All sections
  * Note: I do not want to have double borders when this control is focused
    * Changing to a darker color would be enough
  * We will need to be able to use Color Emoji fonts ( for text entry ) for this component 

* TDaisyToggle, TDaisyFmxToggle :
  * Found at: https://daisyui.com/components/toggle/
  * See sections : All sections are needed

# Demos: IMPORTANT

- Please DO NOT generate visual components "on the fly"
- It means that they cannot be moved around, resized or altered easily
  - It's a very BAD way to do a UI
  
- ## Theme switcher

The theme switcher should be added to the demo, it should include all the new themes


## Icons for the components on the component palette

Please ensure that icons are created for any new component added to the components in the "Daisy FMX" and "Daisy VCL" section of the Component Palette.

- They need to look professional
- They need to be consistent with the other icons
- They need to be as colorful as the other icons
- We always need a different icon for each component
  - However, these icons can be shared across the "Daisy FMX" and "Daisy VCL" set
  - So, for instance, the TDaisyFmxButton would have the same icon as the TDaisyVclButton
