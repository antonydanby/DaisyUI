**In the TSVGImage is it possible to do multi-color vectors rather than just monochrome**

The user wants to know if TDaisySVGImage supports multi-color vectors - I should check the current TDaisySVG/DaisyCommon implementation to see.
Searching for 'IconFilled|fill=|stroke=|fu...'✅

Yes, it's possible. Right now it isn't supported. TDaisySVG.IconPath flattens the SVG to a single path string, and the control draws that in one colour, either stroked or filled. Any per-element fill= or stroke= colours are discarded.
To get multi-colour I would:

Parse each <path>, <circle>, <rect> and the other shapes into a separate layer. Each layer would carry its own fill colour, stroke colour, stroke width and opacity. currentColor would still follow the theme.
Handle <g> inheritance and <linearGradient>. Gradients could be approximated as the first stop colour, or as a real gradient in GDI+ and FMX.
Add a Colored option. When it is on, the SVG's own colours are used. When it is off, the icon stays monochrome as it is today.
Do all of this without a DLL, since GDI+ and FMX both draw coloured paths natively.
Limits: no CSS <style> blocks, filters, masks or text elements.
Shall I implement it in TDaisySVG and both frameworks?
