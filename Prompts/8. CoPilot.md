# Actions

If you look in the Standard VCL library you will see a lot of components, such as TCheckBox and TButton have an .Action property so that they can use events and properties from TAction's held on a TActionList and even use the TActionList.OnUpdate event and other events as well as properties like the .State.

- I'd like you to implement these across the Daisy VCL and FMX components 
  - There is no point for labels and stat's and other similar controls that are not changing or whose events it does not make sense to control in this manner
  - However things like check boxes and buttons are ideal candidates
- When you are ready add TActionList's to the demo's and create TAction's and hook them to the controls
