### Please add the following ( not a part of Daisy UI, but we will need them ):

* TDaisyFormStyler, TDaisyFmxFormStyler:
  * Non-Visual component
  * Additional to a TForm
  * Is aware of and controls settings for TDaisyControl themes and .ThemedTitleBar
  * By default it must have TDaisyControl.ThemedTitleBar := True;
  * It needs an ApplyTheme(const aTheme: TDaisyThemeKind) public method
  * When you have created this all the demos need to use this form styler

* TDaisyMainMenu, TDaisyFmxMainMenu:
  * Similar to a TMainMenu
  * Differs in that it inherits from TDaisyControl and uses styles etc...
  * Must have .SVG so that menu icons can be SVG; limited to 32x32, 24x24 or 16x16 pixels

* TDaisyMenu, TDaisyFmxMenu:
  * Found at: https://daisyui.com/components/menu/
  * See sections : All sections
  * Note: It will be quite distinct from TDaisyMainMenu, TDaisyFmxMainMenu

* TDaisyPopupMenu, TDaisyFmxPopupMenu:
  * Similar to a TPopupMenu
  * Differs in that it inherits from TDaisyControl and uses styles etc...
  * Must have .SVG so that menu icons can be SVG; limited to 32x32, 24x24 or 16x16 pixels
