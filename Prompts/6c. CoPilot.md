# Creating a new PeakSVG package

In the DaisyUI packages there are several components I wish for you to look at and use to create a brand new **VCL only** package, re-using code where possible to save re-invention

The source code units in question are:

Daisy.SVG, Daisy.VCL.Control and Daisy.VCL.SVGImage

The new components I want you to create are:

- TPeakSVG ( saved to file as Peak.SVG.pas )
  - I want exactly the same functionality as TDaisySVG
  - However, we need to drop reliance on Daisy.VCL.Control
  - Instead of Daisy.VCL.Control we need just the SVG functionality and logic from Daisy.VCL.Control and this needs to go into TPeakSVGBase ( saved to file as Peak.SVG.Base.pas )

- TPeakSVGImage ( saved to file as Peak.SVGImage.pas )
  - I want exactly the same functionality as TDaisySVGImage
  - However, we need to drop on reliance Daisy.VCL.Control
  - Instead of Daisy.VCL.Control we need just the VSG functionality and logic from Daisy.VCL.Control and this needs to go into TPeakSVGBase ( saved to file as Peak.SVG.Base.pas )

- These components all need to go into a "Peak SVG" section in the component pallette

## New component

I require a new component/class in a new file ( Peak.SVG.Lists.pas )
The class/component will be TPeakSVGImageList

- This TPeakSVGImageList control will be similar to TImageList in the VCL
- It will hold a list of SVG images as TList<TPeakSVGImageListItem>
- It will require a constructor to create the list and a destructor to free and destroy the list
- Each TPeakSVGImageListItem will contain:
  - The following properties: SVG: string, Caption: string, Tag: NativeInt, Coloured: True/False, Height: Integer, Width: Integer, Tag: String;
  - A property editor 
  - The following methods: Load ( to load from a single file ), Clear to clear the SVG contents
- TPeakSVGImageList will contain:
  - The following methods: Create, Destroy, Load ( Single file, multiple files or all files in a folder ( and optionally sub-folders ) )
  - The following properties: Items: TList<TPeakSVGImageListItem>
  - Tag: integer;
- Please use your judgement to decide if there needs to be other properties and methods such as those I have forgotten

## New Base functionality

I require a new class in a new file ( Peak.SVG.Conversion.pas )
The class will be TPeakSVGConversion

In this new TPeakSVGConversion I require the following functionality

- SVG to PNG conversion
- SVG to BMP conversion
- SVG to JPG conversion
- SVG to ICO conversion

- PNG to ICO conversion

- PNG to SVG conversion
- BMP to SVG conversion
- JPG to SVG conversion

## NOTE:

- I don't require pixel perfection, but the closer we can get, the better
- DLL's cannot be used

## Demo's

- I want a small VCL single form demo showing off all this functionality
- The demo needs to work with single files
- The demo needs to work with a list of files
- The demo needs to work with files found in a folder ( and optionally sub-folders )
