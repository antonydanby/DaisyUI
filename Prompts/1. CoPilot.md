# DaisyUI package

- I want to create Delphi components based on the UI elements found at https://daisyui.com. 
  - These are Tailwind CSS plugins. 
  - I am only wanting to create the look, feel and behaviour of a large number of these
- I need both a VCL and an FMX version of these components
  - The VCL will likely have to use GDI+/Direct2D.
- These components should be added to @DaisyVCLpkg and @DaisyFMXpkg

We must start with a TDaisyControl for VCL and FMX that acts as a Base Class.

So for example:

TDaisyControl = class(TCustomControl)
protected
  procedure Paint; override;
public
  Theme: TDaisyTheme;
  Padding: Integer;
  CornerRadius: Integer;
  ShadowSize: Integer;
end;

Then all components inherit from it:

* TDaisyButton = class(TDaisyControl)
* TDaisyCard = class(TDaisyControl)
* TDaisyAlert = class(TDaisyControl)

This will allow:

* unified theme
* unified spacing
* unified rendering
* unified behaviour

Anything that is common and that all components require should be placed into TDaisyControl

## NOTE: 

- I don't require pixel perfection, but the closer we can get to look, the better
- Not all of the components are need, not will all of them be named in the same manner

Please start with:

* TDaisyControl
* TDaisyButton = class(TDaisyControl)
* TDaisyCard = class(TDaisyControl)
* TDaisyAlert = class(TDaisyControl)

Then, once you have done these can you:

- add demonstrations for them to @MainVCL.pas and @MainFMX.pas in the demos folder

# Demos: IMPORTANT

- Please DO NOT generate visual components "on the fly"
- It means that they cannot be moved around, resized or altered easily
  - It's a very BAD way to do a UI
- Please correct @MainVCL.pas and @MainFMX.pas now that you know how I feel about it
